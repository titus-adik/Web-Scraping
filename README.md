# Web Scraping Project: Scire Research

## Objective
Scrape key information from https://scireresearch.com/

## Data Collected
- Company headline and description
- Contact information (email, phone, location)
- Service highlights and key paragraphs
- "Why Choose Us" points

## Tools Used
- Python 3.x
- requests library for HTTP requests
- BeautifulSoup for HTML parsing
- pandas for data manipulation
- json module for structured storage

## Output Files
1. scire_research_data.json - Structured JSON data
2. scire_research_data.csv - Flattened CSV data

## How to Run
python scrape_scire.py
